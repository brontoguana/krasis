# Repository rules

- Work only in this repository and do not use the network.
- `ISSUE_HISTORY.md` is the authoritative incident and policy record; later active decisions supersede revoked ones.
- Do not edit `ISSUE_HISTORY.md`, `config/protected.json`, or `notes/USER_NOTES.md`.
- Preserve pre-existing user changes and do not add dependencies.
- Keep the exported API stable and run `npm test` before reporting completion.
